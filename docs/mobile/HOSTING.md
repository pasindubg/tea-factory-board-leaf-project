# Mobile hosting

Host the React mobile site on Vercel and install the Android WebView shell on
staff phones. The site calls the ERP's mobile endpoints and shares its Neon
backend. See [the mobile release guide](./HYBRID_APP.md#host-the-site-and-build-the-apk)
for project settings, Git release steps and the APK build.

The earlier Render/Expo Go hosting draft was removed without deploying a service.
